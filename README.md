# Control Proveedores 2026 · MDA Inmobiliaria

Aplicación web (GitHub Pages) para el control de Órdenes de Compra, Facturas y Boletas, con datos en listas de SharePoint vía Microsoft Graph.

Clonada desde [alacalufexd/Control-Proveedores](https://github.com/alacalufexd/Control-Proveedores) y adaptada a la identidad visual de MDA Inmobiliaria (azul corporativo `#013186` y logo en `assets/`).

- `index.html` — aplicación
- `config.js` — IDs de Azure AD / SharePoint
- `SETUP.md` — guía de configuración
